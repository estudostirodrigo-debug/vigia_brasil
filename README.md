# 🇧🇷 Vigia Brasil

> Plataforma em desenvolvimento para auxiliar cidadãos na consulta, análise e fiscalização de contratos públicos.

---

## 📖 Sobre o projeto

O **Vigia Brasil** nasceu com o objetivo de tornar as informações sobre contratos públicos mais acessíveis à população.

A plataforma permitirá que qualquer cidadão pesquise contratos, licitações e despesas públicas de forma simples, contribuindo para a transparência e o controle social.

Este projeto está sendo desenvolvido como parte da minha jornada de estudos em Desenvolvimento de Software.
